# Jbisfun Tap

Formulae the jbisfun workspace needs that homebrew/core doesn't ship, or ships in a form
that doesn't work for us. Each formula says why it's here.

| Formula | Why |
| --- | --- |
| `ldoc` | Not in homebrew/core; v1.5.0 breaks on Lua 5.5, so it's built from upstream master. |

## How do I install these formulae?

`brew install jbisfun/tap/<formula>`

Or `brew tap jbisfun/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jbisfun/tap"
brew "<formula>"
```

With [tool](https://github.com/jbisfun/tool) / `pull tool`, list the tap in the pullfile
`tool` section (`tap = [jbisfun/tap]`): tap formulae override homebrew/core ones of the
same name. tool reads `api/` (formulae.brew.sh-shaped JSON, regenerated by
`bin/generate-api` whenever bottles are published) since it doesn't evaluate Ruby.

## Adding or changing a formula

Open a pull request: `brew test-bot` builds and tests bottles on Linux and macOS. When it's
green, run the `brew pr-pull` workflow with the PR number; it uploads the bottles to a
GitHub release, commits the `bottle do` block and the API JSON, and pushes to main.
